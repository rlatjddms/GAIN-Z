# 밴드 커뮤니티 UI 테스트

`frontend`에서 최초 한 번 설치하고 실행한다.

```sh
npm ci
npx playwright install chromium --only-shell
npm run test:community
```

테스트는 127.0.0.1:4179에 Vite를 띄우고 종료 시 정리한다. 해당 포트는 비어 있어야 한다.
별도 브라우저 컨텍스트와 가짜 로그인·API를 사용하므로 실제 계정·밴드 데이터는 변경하지 않는다.

공지 우선 목록·페이지 이동, 작성·수정·첨부 삭제, 첨부 실패 후 중복 생성 없는 재시도,
댓글·대댓글·삭제 표시, 권한별 버튼, 오류 재시도, 홈 진입 경로와 모바일 가로 넘침을 검증한다.
결과 화면은 Git에서 제외된 `test-results/`에 저장한다.

이 테스트는 실제 백엔드·MariaDB·Redis를 연결한 통합 테스트가 아니다. 실제 사용에는 #94 API가 필요하다.
