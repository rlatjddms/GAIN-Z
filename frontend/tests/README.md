# 밴드 커뮤니티 UI 테스트

`frontend`에서 최초 한 번 설치하고 실행한다.

```sh
npm ci
npx playwright install chromium --only-shell
npm run test:community
```

테스트는 127.0.0.1:4179에 Vite를 띄우고 종료 시 정리한다. 해당 포트는 비어 있어야 한다.
별도 브라우저 컨텍스트와 가짜 로그인·API를 사용하므로 실제 계정·밴드 데이터는 변경하지 않는다.

홈 공지·목록 더 보기, 상단바를 유지하는 상세·작성 다이얼로그, 작성자 우선 배치, 사진·영상 다중 미리보기와 재생, 공지 설정·첨부 삭제, 서버 저장 실패 후 초안을 보존하는 재시도,
댓글·대댓글·삭제 표시, 권한별 편집, 미저장 변경 확인, 첨부 8개 제한, 오류 재시도, 기존 URL 리다이렉트와 모바일 가로 넘침을 검증한다.
결과 화면은 Git에서 제외된 `test-results/`에 저장한다.

이 테스트는 실제 백엔드·MariaDB·Redis를 연결한 통합 테스트가 아니다. 실제 사용에는 #94 API가 필요하다.

추가 검증: 내 글 필터의 페이지 이동과 카드 수정·삭제, 이미지 확대·넘기기·개별/ZIP 다운로드, 한글 IME 조합 첫 글자 등록, 답글 접기·대상 태그, @멤버 자동완성 및 강조 표시. 멘션은 본문 텍스트로 저장하며 별도 알림 전송은 포함하지 않는다.
