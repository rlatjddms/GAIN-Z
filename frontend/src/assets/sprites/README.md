# 픽셀 캐릭터 스프라이트

캐릭터는 아래 레이어 PNG를 순서대로 겹쳐서 그립니다. 모든 파일은 **24×32**, 배경 투명, 1배 크기입니다.

| 폴더 | 파일명 | 비고 |
|---|---|---|
| `body/` | `FEMALE.png`, `MALE.png` | 백엔드 `Gender` 값 |
| `outfit/` | `DEFAULT.png` | 의상. 추후 `OutfitItem`과 연결 |
| `hair/` | `BALD.png` … `MOHAWK_SHARP.png` | 백엔드 `HairStyle` 값 |
| `instrument/` | `GUITAR.png` … `KEYBOARD.png` | 백엔드 `InstrumentType` 값 |

파일명이 백엔드 enum 값과 같으면 코드 수정 없이 자동으로 인식됩니다 (`src/pixel/sprites.js`).

## 기준색 (런타임에 사용자 색으로 치환)

아래 색으로 칠한 픽셀만 사용자가 고른 색으로 바뀝니다. 하이라이트·그림자·외곽선은 사용자 색에서 자동 계산됩니다.
정의는 `src/pixel/palette.js`에 있습니다.

| 역할 | 기준색 | 치환 결과 |
|---|---|---|
| 머리 기본 | `#FF00FF` | 머리색 |
| 머리 하이라이트 | `#FF80FF` | 머리색 +48 |
| 머리 그림자 | `#B000B0` | 머리색 −42 |
| 머리 외곽선 | `#600060` | 머리색 −90 |
| 악기 기본 | `#00FFFF` | 악기색 |
| 악기 그림자 | `#00B0B0` | 악기색 −48 |
| 악기 외곽선 | `#006060` | 악기색 −95 |
| 의상 기본 | `#FFFF00` | 의상색 |
| 의상 그림자 | `#B0B000` | 의상색 −40 |
| 의상 외곽선 | `#606000` | 의상색 −85 |

그 외의 색(피부 `#f8d7b5`, 피부 외곽선 `#9c5b36`, 눈 `#3a2622`, 청바지 `#4a7bc8`, 신발 `#1f1f23` 등)은 PNG에 있는 그대로 그려집니다. 기본 의상색은 흰색(`#FFFFFF`)입니다.

## 확인하기

개발 서버에서 `/dev/sprites` 로 접속하면 모든 머리·악기 조합과 색 치환 결과를 볼 수 있습니다.
