# 픽셀 캐릭터 스프라이트

캐릭터는 아래 레이어 PNG를 순서대로 겹쳐서 그립니다. 모든 파일은 **24×32**, 배경 투명, 1배 크기입니다.

| 폴더 | 파일명 | 비고 |
|---|---|---|
| `body/` | `FEMALE.png`, `MALE.png` | 백엔드 `Gender` 값 |
| `outfit/` | `DEFAULT_FEMALE.png`, `DEFAULT_MALE.png` | 의상. 체형이 달라 `<이름>_<성별>.png`로 두고, 없으면 `<이름>.png`를 씀. 추후 `OutfitItem`과 연결 |
| `hair/` | `BALD.png` … `MOHAWK_SHARP.png` | 백엔드 `HairStyle` 값 |
| `instrument/` | `GUITAR.png` … `KEYBOARD.png` | 백엔드 `InstrumentType` 값 |
| `shoes/` `neck/` `glasses/` `hat/` | `SNEAKERS.png` … `CROWN.png` | 레벨 보상 소품. 백엔드 `Accessory` 값, 목록은 `src/constants/rewards.js` |

그리는 순서(아래 → 위): `body` → `shoes` → `outfit` → `neck` → `hair` → `glasses` → `hat` → `instrument`.

소품 자리 (두 성별의 머리·발 위치가 같아서 소품은 공용 파일 하나):

| 자리 | 위치 |
|---|---|
| 모자 | 머리 위 y0~7 (머리카락 위에 그림) |
| 안경 | 눈 y8~10, 왼눈 x8~9, 오른눈 x14~15 |
| 목 | 목·가슴 y14~20 |
| 신발 | 발 y29~31, x7~16 (높은 신발은 y27부터) |

레벨 보상 의상(`HOODIE` 등)은 사용자가 색을 고르지 않으므로 고정색으로 칠합니다. 레벨 보상 헤어는 다른 머리처럼 머리 기준색으로 칠합니다.

파일명이 백엔드 enum 값과 같으면 코드 수정 없이 자동으로 인식됩니다 (`src/pixel/sprites.js`).

## 기준색 (런타임에 사용자 색으로 치환)

아래 색으로 칠한 픽셀만 사용자가 고른 색으로 바뀝니다. 하이라이트·그림자·외곽선은 사용자 색에서 자동 계산됩니다.
정의는 `src/pixel/palette.js`에 있습니다.

| 역할 | 기준색 | 치환 결과 |
|---|---|---|
| 피부 기본 | `#F8D7B5` | 피부색 |
| 피부 하이라이트 | `#FDE7CF` | 피부색 +12 |
| 피부 그림자 | `#E3B48D` | 피부색 −32 |
| 피부 외곽선 | `#9C5B36` | 피부색 −105 |
| 머리 기본 | `#FF00FF` | 머리색 |
| 머리 하이라이트 | `#FF80FF` | 머리색 +48 |
| 머리 그림자 | `#B000B0` | 머리색 −42 |
| 머리 외곽선 | `#600060` | 머리색 −90 |
| 악기 기본 | `#00FFFF` | 악기색 |
| 악기 하이라이트 | `#80FFFF` | 악기색 +40 |
| 악기 그림자 | `#00B0B0` | 악기색 −48 |
| 악기 외곽선 | `#006060` | 악기색 −95 |
| 의상 기본 | `#FFFF00` | 의상색 |
| 의상 그림자 | `#B0B000` | 의상색 −40 |
| 의상 외곽선 | `#606000` | 의상색 −85 |

그 외의 색(눈 `#3a2622`, 청바지 `#3f6db5`, 신발 `#2b2d31` 등)은 PNG에 있는 그대로 그려집니다. 기본 피부색은 `#F8D7B5`, 기본 의상색은 흰색(`#FFFFFF`)입니다. 피부 기준색은 일부러 실제 피부색과 같은 값이라, 기본 피부색일 때 원본 그림과 거의 같게 보입니다.

## 확인하기

개발 서버에서 `/dev/sprites` 로 접속하면 모든 머리·악기 조합과 색 치환 결과를 볼 수 있습니다.
