# 모바일 대응 방식: 반응형 웹 → PWA → 웹 푸시 (#123)

휴대폰에서 GAIN-Z를 어떻게 쓰게 할지 비교하고 정한 내용입니다.

- 반응형 웹: #124 (PR #146)
- PWA: #143 (PR #152)
- UI 통일: #122, #134, #135

## 1. 선택지 비교

| 방식 | 작업량 | 장점 | 단점 |
| --- | --- | --- | --- |
| 반응형 웹 | 중 (화면마다 손봄) | 지금 화면을 휴대폰 브라우저에서 바로 씀. 아래 방식도 모두 이게 먼저 필요 | 홈 화면 아이콘·전체 화면 실행 없음 |
| PWA | 소 (반응형 위에 매니페스트·아이콘·서비스 워커) | 홈 화면 설치, 앱 아이콘, 주소창 없는 전체 화면 실행 | 웹 푸시는 아이폰에서 홈 화면에 설치했을 때만(iOS 16.4 이상) |
| 앱 감싸기 (Capacitor 등) | 중~대 | 스토어 배포 | 빌드·심사·인증서 관리. 지금 단계에선 얻는 게 적음 |
| 네이티브 앱 | 대 | 기능 제약이 가장 적음 | 처음부터 다시 만들어야 함 |

## 2. 결정

**반응형 웹 → PWA → (필요하면) 웹 푸시** 순서로 진행합니다.

- 앱 감싸기·네이티브는 지금 하지 않습니다. 녹음·재생·악보 보기가 모두 브라우저 기능으로 되고, 스토어 배포가 꼭 필요한 이유가 아직 없습니다.
- 웹 푸시(앱을 닫아도 오는 알림)는 휴대폰 설치를 확인한 뒤 따로 정합니다.

## 3. 기능별 확인 (코드 기준)

| 기능 | 쓰는 기술 | 휴대폰에서 |
| --- | --- | --- |
| 레이어 잼 녹음 | `MediaRecorder` (`JamEngine.pickRecordingType`이 지원 형식을 고름) | 안드로이드 크롬 지원, 아이폰 사파리 14.3부터 지원(`audio/mp4`) |
| 재생·메트로놈 | Web Audio | 사용자가 화면을 누른 뒤에만 소리가 남. 재생 버튼에서 시작하는 지금 구조로 문제없음 |
| 악보 보기 | 이미지·PDF | 좁은 화면 배치는 #124에서 처리 |
| 실시간 알림 (SSE) | `EventSource` | 앱을 내리면 연결이 끊기고, 다시 열면 이어지며 안 읽은 수를 다시 불러옴. 앱을 닫아도 오는 알림은 웹 푸시가 필요 |
| 입력칸 | — | 아이폰은 16px보다 작은 입력칸을 누르면 화면을 확대함. `maximum-scale=1`로 막음(안드로이드 크롬은 두 손가락 확대도 막힘) |

## 4. 반응형 웹에서 정한 기준 (#124)

- 화면 너비: 휴대폰 ≤ 640px, 태블릿 ≤ 860px
- 휴대폰은 기준 글자 크기를 16px → 14.5px로 줄여 화면 전체를 같은 비율로 (글자 크기가 대부분 rem)
- 팝업은 휴대폰에서 아래에서 올라오는 시트
- 뒤로 가기: 휴대폰은 헤더 왼쪽 화살표, 넓은 화면은 상위 화면이 홈이 아닐 때만
- 버튼 높이: 주요 36px, 작은 도구 32px (손가락으로 누르는 화면 기준)

## 5. PWA 구성 (#143)

- `public/manifest.webmanifest`: 이름 "GAIN-Z", 전체 화면(`standalone`), 시작 화면 `/home`
- `public/icons/`: 로고의 번개 Z를 민트 바탕에 (192·512·maskable·apple-touch)
- `public/sw.js`: 같은 주소의 화면 파일만 캐시, API는 건드리지 않음. 배포 빌드에서만 등록

## 6. 실제 기기 확인

휴대폰 설치는 https 주소(또는 localhost)에서만 됩니다. 배포 전에는 아래처럼 확인합니다.

| 방법 | 확인할 수 있는 것 |
| --- | --- |
| 컴퓨터 크롬 + `npm run build` → `npm run preview` (localhost:4173) | 설치, 앱 아이콘·이름, 전체 화면 실행, 서비스 워커 |
| 안드로이드 USB 연결 + `chrome://inspect` 포트 포워딩(4173) | 휴대폰 설치·실행 |
| 아이폰 사파리, 같은 와이파이 IP | 홈 화면 추가·아이콘·전체 화면 (http라 서비스 워커는 안 켜짐) |

휴대폰에서 로그인·기능까지 쓰려면 배포가 필요합니다. 화면이 백엔드를 `localhost:8080`으로 부르고, 간편로그인 성공 주소도 `localhost:5173`으로 고정돼 있기 때문입니다.

확인할 목록 (배포 뒤):

- [ ] 안드로이드 크롬: 설치, 아이콘, 전체 화면, 레이어 잼 녹음·재생
- [ ] 아이폰 사파리: 홈 화면 추가, 아이콘, 레이어 잼 녹음(`audio/mp4`)·재생, 입력칸 확대 안 됨
- [ ] 두 기기: 알림이 앱을 다시 열면 이어지는지, 안 읽은 수가 맞는지
