# 마디 악보 데이터(`TabData.noteData`) 포맷

AI가 만든 악보(#53)나 앞으로 직접 쓰는 타브 악보는 마디 하나를 `TabData` 한 줄로 저장합니다.
`noteData`에는 그 마디의 박자·코드·음을 **JSON 문자열**로 넣습니다.
프론트 렌더러(`frontend/src/music/noteData.js`, `components/workspace/TabSheet.vue`, `ChordChart.vue`)가 이 포맷을 읽습니다.

## TabData 한 줄

| 컬럼 | 설명 |
| --- | --- |
| `measureNumber` | 마디 번호. 1부터 시작해서 하나씩 늘어남 |
| `noteData` | 아래 JSON (마디 하나) |
| `recommendedFingering` | 선택. 이 마디를 칠 때 쓰는 운지 안내 문구 (예: `5프렛 포지션, 검지로 바레`). 마디 아래에 작게 보여 줌 |

## noteData JSON

```json
{
  "timeSignature": "4/4",
  "section": "Verse 1",
  "chords": [
    { "beat": 0, "name": "C" },
    { "beat": 2, "name": "G/B" }
  ],
  "notes": [
    { "beat": 0, "duration": 0.5, "string": 5, "fret": 3 },
    { "beat": 0.5, "duration": 0.5, "string": 3, "fret": 0 },
    { "beat": 1, "duration": 0.5, "string": 2, "fret": 1, "technique": "hammer" },
    { "beat": 1.5, "duration": 0.5, "string": 2, "fret": 3 }
  ]
}
```

모든 필드는 생략할 수 있습니다. 빈 마디는 `{}`입니다.

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `timeSignature` | 문자열 `"분자/분모"` | 박자. 박자가 바뀌는 마디에만 적습니다. 생략하면 앞 마디 박자를 이어받고, 첫 마디에서 생략하면 `4/4`입니다. 분모는 2·4·8·16 |
| `section` | 문자열 | 이 마디부터 시작하는 구간 이름 (`Intro`, `Verse 1`, `후렴` …). 40자 이하 |
| `chords` | 배열 | 이 마디의 코드. 코드 악보와 타브 위 코드 표시에 씁니다 |
| `chords[].beat` | 숫자 | 마디 첫 박에서 몇 박 뒤에 나오는지 (아래 "박" 참고) |
| `chords[].name` | 문자열 | 코드 이름. `C`, `F#m7`, `Bbmaj7`, `D/F#`, `Asus4` 같은 형식. `N.C.`처럼 코드로 읽히지 않는 이름은 키를 바꿔도 그대로 둡니다 |
| `notes` | 배열 | 타브로 그릴 음 |
| `notes[].beat` | 숫자 | 마디 첫 박에서 몇 박 뒤인지 |
| `notes[].duration` | 숫자 | 선택. 길이(박). 렌더러는 지금은 쓰지 않지만 박자 표시·재생용으로 남겨 둡니다 |
| `notes[].string` | 정수 | 줄 번호. **1번 줄이 가장 높은 음** (기타: 1 = 높은 E, 6 = 낮은 E / 베이스: 1 = G, 4 = E) |
| `notes[].fret` | 정수 0~24 | 프렛. 개방현은 0. `technique`가 `mute`면 생략할 수 있습니다 |
| `notes[].technique` | 문자열 | 선택. 아래 주법 중 하나 |

### 박

- **박은 항상 4분음표 하나 = 1**입니다. 박자표 분모와 상관없습니다.
  - 4/4 한 마디 = 4박, 3/4 = 3박, 6/8 = 3박 (8분음표 하나 = 0.5), 2/2 = 4박
- 소수로 적습니다. 8분음표 = 0.5, 16분음표 = 0.25, 셋잇단 8분음표 = 0.333 (소수 셋째 자리까지)
- `0 ≤ beat < 마디 길이`. 범위를 벗어난 음·코드는 그리지 않습니다.
- 같은 `beat`에 여러 음이 있으면 화음(동시에 치는 음)입니다.

### 주법 (`technique`)

| 값 | 뜻 | 타브 표시 |
| --- | --- | --- |
| `hammer` | 해머링 온 (앞 음에서 이 음으로) | 앞 음과 이 음 사이에 `h` |
| `pull` | 풀링 오프 (앞 음에서 이 음으로) | `p` |
| `slide` | 슬라이드 (앞 음에서 이 음으로) | 높아지면 `/`, 낮아지면 `\` |
| `bend` | 벤딩 | 숫자 뒤에 `b` |
| `vibrato` | 비브라토 | 숫자 뒤에 `~` |
| `mute` | 브러싱(뮤트) | `x` |
| `harmonic` | 하모닉스 | `<12>`처럼 꺾쇠 |

`hammer`, `pull`, `slide`의 "앞 음"은 같은 줄에서 바로 앞에 나온 음입니다 (앞 마디의 마지막 음일 수도 있습니다).

## 악기와 줄 수

- 줄 수와 조율은 악보의 `instrumentType`으로 정합니다. 지금은 표준 조율만 씁니다.
  - `GUITAR`: 6줄, E A D G B E
  - `BASS`: 4줄, E A D G
- 다른 악기(`DRUM`, `KEYBOARD`, `VOCAL`)는 타브를 그리지 않고 코드 악보만 보여 줍니다.
- 줄 수를 넘는 `string`의 음은 그리지 않습니다.

## 키 바꾸기

보는 키를 바꾸면 렌더러가 원래 키(`SheetMusic.originalKey`)에서 몇 반음 옮길지 계산해 아래처럼 바꿔 보여 줍니다. 저장된 데이터는 바뀌지 않습니다.

- 코드 이름: `music/transpose.js`의 `transposeChord`로 옮깁니다 (플랫 키면 b로 표기).
- 프렛: 운지 모양이 깨지지 않게 **악보 전체를 같은 반음 수만큼** 옮깁니다. `반음 수`, `반음 수 − 12`, `반음 수 + 12` 가운데 모든 음이 0~24프렛에 들어가는 것 중 이동이 가장 작은 것을 씁니다.
  - 예) C → Bb(−2반음)인데 개방현(0프렛)이 있으면 +10프렛으로 옮깁니다.
  - 셋 다 안 되면 음마다 옮기고, 0보다 작아진 음은 +12, 24보다 커진 음은 −12 합니다.
- `recommendedFingering`은 원래 키 기준 안내라서 키를 옮기면 숨깁니다.

## 잘못된 데이터

렌더러는 읽을 수 없는 마디(JSON 오류, 객체가 아님)를 빈 마디로 그리고 "읽을 수 없는 마디" 표시를 붙입니다.
잘못된 필드 하나 때문에 악보 전체가 안 보이는 일은 없게 합니다.

## 바꿀 때

이 포맷을 바꾸면 이 문서, `frontend/src/music/noteData.js`, AI 악보 생성(#53)을 함께 고칩니다.
필드를 빼거나 뜻을 바꾸지 말고, 새 필드를 더하는 쪽으로 바꿉니다.
