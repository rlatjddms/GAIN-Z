# GAIN-Z 도트 공방

캐릭터 스프라이트 PNG(`frontend/src/assets/sprites/`)를 브라우저에서 직접 찍고 저장하는 편집기입니다.
설치할 것은 없고 Node.js 18 이상만 있으면 됩니다.

## 실행

```bash
node tools/dot-studio/server.cjs
```

Windows에서는 `tools/dot-studio/dot-studio.cmd`를 더블클릭해도 됩니다.
브라우저가 자동으로 열리고(`http://127.0.0.1:5179`), 탭을 닫으면 서버도 꺼집니다.

## 화면

- **위 탭**: 레이어 선택 (몸 / 하의 / 신발 / 의상 / 허리 / 목 / 머리 / 귀걸이 / 모자 / 안경 / 악기). 레이어마다 PNG 폴더가 따로 있습니다. 하의·소품은 레벨 보상이고 목록은 `frontend/src/constants/rewards.js`에 있습니다.
- **왼쪽**: 그 레이어의 스프라이트 목록. 이름을 입력하고 **추가**하면 지금 보고 있는 그림을 복제해서 새 스프라이트가 시작됩니다. 파일명은 백엔드 enum 값과 같아야 합니다 (예: `hair/LONG_STRAIGHT.png`).
- **가운데**: 24×32 캔버스. 다른 레이어가 반투명하게 겹쳐 보여서 머리나 악기를 몸 위에 맞춰 그릴 수 있습니다.
- **오른쪽**: 팔레트와 실제 색으로 합성한 미리보기. 미리보기의 머리색·악기색·의상색을 바꾸면 기준색이 어떻게 치환되는지 바로 보입니다.
- **저장**(Ctrl+S)하면 `frontend/src/assets/sprites/<레이어>/<이름>.png`에 바로 써집니다. Vite 개발 서버가 켜져 있으면 `/dev/sprites`와 홈 화면에 즉시 반영됩니다.

## 기준색

머리·악기·의상처럼 사용자가 색을 고르는 부분은 반드시 팔레트의 **기준색**으로 칠해야 합니다.
런타임에 그 색만 사용자 색으로 바뀌고, 그림자·하이라이트·외곽선은 자동으로 계산됩니다.
목록은 `frontend/src/assets/sprites/README.md`와 `frontend/src/pixel/palette.js`에 있습니다.

## 단축키

| 키 | 동작 |
|---|---|
| B / E / F / I | 펜 / 지우개 / 채우기 / 색 뽑기 |
| R | 선택: 드래그로 네모 영역 선택, 영역 안을 잡고 끌면 그 부분만 이동. 클릭만 하면 선택 해제 |
| V | 이동: 선택 영역이 있으면 그 부분만, 없으면 그림 전체를 칸 단위로 이동 |
| 방향키 | 선택 영역을 한 칸씩 이동. 선택이 없으면 그림 전체 (가장자리에 닿으면 멈춤) |
| Ctrl+C / Ctrl+X / Ctrl+V | 선택 영역 복사 / 잘라내기 / 붙여넣기 (선택이 없으면 그림 전체 복사). 다른 스프라이트·레이어에도 붙여넣을 수 있음 |
| Ctrl+A / Esc | 전체 선택 / 선택 해제 (떠 있던 그림을 그 자리에 내려놓음) |
| Delete | 선택 영역 지우기 |
| 오른쪽 클릭 | 지우개 |
| Alt+클릭 | 색 뽑기 |
| Shift+클릭 | 직전 점에서 직선 |
| M | 좌우 대칭 |
| Tab | 다른 레이어 겹쳐 보기 |
| G | 격자 |
| W / S | 현재 색 밝게 / 어둡게 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 |
| Ctrl+S | 저장 |
| Space+드래그, 휠 클릭 드래그 | 캔버스 이동 |
| 휠 | 확대 / 축소, 0 = 화면에 맞춤 |

## 출처

HotelOfTheDead 레포의 도트 공방(`tools/pixelrig/paint`, 유민준)에서 캔버스·도구·팔레트 부분을 가져와 GAIN-Z 규격에 맞게 다시 썼습니다.
